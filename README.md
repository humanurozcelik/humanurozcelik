# Hüma Nur Özçelik

I am a fourth-year Biomedical Engineering student at Ankara University.

I am mainly interested in biomedical signal processing, medical device software, and systems engineering. I usually work with Python and MATLAB/Simulink, and most of my projects are related to ECG, computer vision, or biomedical data.

## Projects

### 12-Lead ECG Viewer
A Python desktop application I developed during my internship for 12-channel ECG visualization and analysis. It includes filtering, QRST landmark estimation, MMA-style T-wave alternans analysis, and pacemaker-artifact candidate visualization.

[View project](https://github.com/humanurozcelik/12-lead-ecg-viewer)

### Webcam Gaze Tracking
A webcam-based gaze-tracking project using MediaPipe, binocular eye images, a shallow CNN, calibration, and Kalman filtering.

[View project](https://github.com/humanurozcelik/cnn-kalman-gaze-tracker)

### ECG Monitoring with MATLAB & Simulink
A signal-processing project for ECG filtering, R-peak detection, heart-rate estimation, and Simulink-based monitoring.

[View project](https://github.com/humanurozcelik/ecg-realtime-monitoring)

### Fetal Health Classification
A machine-learning bootcamp project using CTG-derived features. I compared several classification models and focused on class imbalance, cross-validation, and avoiding data leakage.

[View project](https://github.com/humanurozcelik/fetal-health-ctg-classification)
