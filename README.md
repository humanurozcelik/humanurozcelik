## Project Highlights

### 12-Lead ECG Viewer & Analysis Prototype
Python desktop application for 12-channel ECG visualization and review, with configurable filtering, QRST landmark estimation, MMA-style T-wave alternans analysis, and pacemaker-artifact candidate visualization.

[View repository](https://github.com/humanurozcelik/12-lead-ecg-viewer)

### Real-Time ECG Monitoring & R-Peak Detection
MATLAB and Simulink-based ECG processing pipeline including band-pass filtering, signal enhancement, adaptive R-peak detection, and real-time simulation.

[View repository](https://github.com/humanurozcelik/ecg-realtime-monitoring)

### CNN + Kalman Webcam Gaze Tracking
Webcam-based gaze tracking prototype combining MediaPipe eye localization, binocular eye-region processing, a shallow CNN, Kalman filtering, and post-hoc trajectory/error analysis.

[View repository](https://github.com/humanurozcelik/cnn-kalman-gaze-tracker)

### Fetal Health Classification from CTG-Derived Features
Machine-learning bootcamp project for three-class fetal health classification using leakage-aware preprocessing, class weighting, cross-validation, hyperparameter optimization, and hold-out evaluation.

[View repository](https://github.com/humanurozcelik/fetal-health-ctg-classification)
