## Project Highlights

### Real-Time ECG Monitoring & R-Peak Detection
MATLAB and Simulink-based ECG processing pipeline including band-pass filtering, signal enhancement, adaptive R-peak detection, and real-time simulation.

[View repository](https://github.com/humanurozcelik/ecg-realtime-monitoring)

### CNN + Kalman Webcam Gaze Tracking
Real-time webcam gaze tracking system combining binocular eye-region processing, a lightweight CNN, dynamic calibration, Kalman filtering, and quantitative trajectory analysis.

[View repository](https://github.com/humanurozcelik/cnn-kalman-gaze-tracker)

### Fetal Health Classification from CTG Data
Machine-learning workflow for three-class fetal health classification using leakage-safe preprocessing, class weighting, cross-validation, hyperparameter optimization, and hold-out evaluation.

[View repository](https://github.com/humanurozcelik/fetal-health-ctg-classification)
